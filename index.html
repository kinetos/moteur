Tu rejoins le tournage

Tu reçois ensuite un QR code : l'équipe le scanne avec l'appareil photo, entre son nom, et c'est parti. Branche tes AirPods ou ton casque avant.

J'ai un code de tournage

Le code, c'est le "numéro de salle" : deux téléphones qui ont le même code se retrouvent dans le même intercom. Il est généré tout seul quand quelqu'un crée le tournage et s'affiche avec le QR code.

Installer comme une app

iPhone : bouton Partager, puis "Sur l'écran d'accueil". Android : menu ⋮, puis "Installer l'application" ou "Ajouter à l'écran d'accueil".
